# Pendentes (para lembrar a Rosa)

## Alunos: «não está associado a este telemóvel» (out/2026)
Os alunos queixam-se de que a aplicação diz que o PIN não está ligado ao telemóvel, mas só usaram esse telemóvel. A Rosa pediu para não fazer já.

Pistas a confirmar:
- O código do telemóvel fica guardado no navegador. O iPhone (Safari) apaga o que as páginas guardam ao fim de uns dias sem as abrir.
- A aplicação aberta pelo ícone do ecrã principal e a aberta no Safari guardam em sítios diferentes, e contam como dois telemóveis.
- Abrir num separador privado ou limpar os dados do navegador tem o mesmo efeito.
