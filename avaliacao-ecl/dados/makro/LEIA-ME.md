# Preços da Makro — atualização mensal

Arraste para esta pasta o ficheiro CSV que a extensão Claude no Chrome
descarregou (um por mês; o nome pode ter a data, ex.: `makro_2026-11-01.csv`).

Em poucos minutos o GitHub refaz o catálogo da aplicação e a aplicação
publica-se com os preços novos. Um ficheiro incompleto ou com outro
formato é recusado e o catálogo fica como estava.
